# Frontend Digital Twin Roadmap v1

Primary user experience is a Hand Digital Twin.

## Navigation
- Overview
- Anatomy
- Tissues
- Cells
- Molecular
- Biological Age
- Health State
- Interventions
- Evidence

## Core Screens

### Twin Viewer
Interactive hand model with region selection.

### Biological Age
Display age at hand, tissue, region and cell-type level.

### Health State
Healthy / At Risk / Diseased / Unknown with confidence.

### Cell Explorer
Cell types, counts, trajectories and evidence.

### Evidence Layer
Every conclusion must expose provenance, uncertainty and supporting modalities.

## Design Rules
- Never hide uncertainty.
- Missing data != healthy.
- Missing data != diseased.
- All biological claims require evidence.
- Surface modality availability to users.
