# Real spatial reference data pipeline

## Purpose

The Digital Twin may use public reference datasets, but a reference dataset is never presented as the user's own anatomy and is never treated as clinical evidence for that user.

## Current reference layers

### Hand geometry

NIH 3DPX-017237 is a healthy-adult human hand anatomical template created from T1-weighted MR images of 27 hands from 21 subjects. It is a reference surface/template, not a scan of the current user.

Source: https://3d.nih.gov/entries/3DPX-017237
Download: https://3d.nih.gov/entries/download/17237/1

### Hand/wrist bones

NIH 3DPX-017249 contains segmented hand/wrist bone geometry derived from the same template.

Source: https://3d.nih.gov/entries/3DPX-017249

### Tissue/cell/molecular references

HuBMAP provides public human tissue datasets, spatial and single-cell data, multimodal assays and Human Reference Atlas structures. These datasets remain in their native dataset coordinate systems unless an explicit registration is supplied.

Source: https://hubmapconsortium.org/hubmap-data/
Portal: https://portal.hubmapconsortium.org/

## Non-negotiable provenance rules

1. A public reference is labelled `REFERENCE`, never `USER_OBSERVATION`.
2. No region/tissue/cell relationship is inferred when the source does not provide it.
3. No coordinate transform is invented.
4. No biological age, health, disease, confidence or trajectory is generated by the frontend.
5. `NOT ESTABLISHED` is used when a required model or dataset is absent.
6. User-uploaded assets use the same adapter/validation contract but remain separate from public references.

## Target pipeline

```text
Public reference or user dataset
        ↓
SpatialSource
        ↓
SpatialDataAdapter
        ↓
SpatialAsset
        ↓
CoordinateSystem + annotations
        ↓
validated geometryId → regionId
        ↓
canonical state
        ↓
3D / tree / inspector / evidence
```

The NIH template currently supplies the hand surface reference. It does not by itself supply validated palm/thumb/index/middle/ring/little/wrist region segmentation, tissue geometry or cell geometry. Those layers require additional source data or explicit annotations.
