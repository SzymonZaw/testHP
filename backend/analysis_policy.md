# Evidence policy

The research output may contain only values computed from files that were successfully read in the current run.

Allowed: descriptive image measurements, tabular numeric summaries, file/format metadata, and structured-node counts.

Not allowed: fabricated scores, synthetic predictions, diagnostic labels, subject links inferred from filenames, or biological conclusions without a validated modality-specific analysis and the necessary evidence.

When required input is missing, malformed, empty, metadata-only, or otherwise insufficient, the output must explicitly state that the result is unavailable and why.
