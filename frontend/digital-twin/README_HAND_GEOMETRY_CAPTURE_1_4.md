# Dopasowanie dłoni — etapy 1–8

Tryb klasyczny pozostaje domyślny. Tryb „Rzeczywista dłoń · pomiary” prowadzi przez:

1. zdjęcia i skalę,
2. pomiary rzeczywistej dłoni,
3. przeliczenie pomiarów na parametry istniejącego modelu 3D,
4. przygotowanie i rejestrację widoków,
5. rekonstrukcję z minimum dwóch widoków,
6. projekcję przygotowanych zdjęć na model.

Proces nie usuwa evidence. Rekonstrukcja jest oznaczona jako wizualizacja badawcza i nie jest metryczną fotogrametrią bez kalibracji kamery.
